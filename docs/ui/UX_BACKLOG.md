# TRACEFOLIO Web UX 修复清单

2026-11-20 · 基于 `e6f9796` 的走查

在 Chrome 的 1440 px 和 390 px 视口走查了九个主页面与简历编辑器。用独立数据库和虚构材料验证首次进入、证据编辑、AI 设置跳转和岗位待办。真实模型生成、导出文件和手机真机体验待专项验证。

| 优先级 | 问题与复现 | 修复后如何验收 |
| --- | --- | --- |
| P1 | 首访自动弹出十步引导，先要求连接 AI。关闭后页面顶部突出「导出职业档案」。 | 新用户可直接添加第一份项目材料，再对照岗位。全站教程从帮助入口打开，AI 配置在相关任务中说明。 |
| P1 | 填写证据时切页签或离开页面会丢失未保存输入。窄屏点击「查看 / 编辑」时，编辑区可能在当前视口上方。 | 切页签来回可恢复草稿。离开未保存的表单前有明确提醒。窄屏打开编辑后马上看到内容与操作。 |
| P1 | 两个窗口修改同一份证据时，旧版本提交返回 `409`，提示刷新且没有保留草稿后加载最新版的入口。 | 保留用户输入，提供查看最新版本和复制草稿的操作。旧版本提交仍会被拦截。 |
| P1 | JD 匹配在提交后才提示设置 AI。从设置返回，JD 输入已清空。 | 提前说明配置状态。返回时恢复本次会话的 JD、简历选择和偏好，用户可以继续提交。 |
| P1 | 从控制中心点具体岗位的面试待办，进入空白面试表单。能力地图和 JD 匹配也需要重复输入岗位信息。 | 从待办直达关联岗位或任务。已有 JD、简历版本和经确认的技能可用于下一步，同时保留手填路径。 |
| P2 | 在 390 × 844 视口，投递看板首个阶段位于约 `1988 px`，操作前需要滚过统计图。控制中心的页面宽度多出 `9 px`。 | 窄屏可以先查看和管理投递记录。统计按需查看。控制中心的内容在视口内换行或重排。 |
| P2 | 职业智能页签按方向键焦点不移动。英文界面仍显示中文页签及部分内容。 | 支持键盘切换，焦点状态可见。中英文标题、页签、字段和可访问名称完整对应。 |

## 随 UI 重构完成

- 职业智能总览为空时突出「整理项目材料」。首次引导的内容与顺序仍待调整。
- 职业记忆和能力证据在本页切换页签时保留输入。手机点击「查看 / 编辑」后焦点进入证据表单。离开整个页面时的草稿恢复仍待处理。
- 投递记录移到统计图前。在原测试视口，首个阶段从约 `1988 px` 提前到约 `503 px`。控制中心在 320、390、768、1024 和 1440 px 视口的整页宽度检查通过。
- 职业智能页签支持方向键操作和中英文标签。其余业务文案的英文覆盖仍待补齐。
